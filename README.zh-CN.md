# Minecraft 语言文件 GUI 编辑器

在 VS Code 中为 Minecraft（数据包 / 资源包 / 模组）语言文件提供**多语言并排的图形化编辑界面**。编辑器以 VS Code 原生 **自定义编辑器（打开方式）** 的形式注册 —— **不拦截任何正常打开行为**，需要时通过 *Open With… / Reopen With…* 显式打开即可。新增、删除或重命名翻译 key 会**同步写入同目录的所有语言文件**，并支持**撤销 / 重做**。

## 功能一览

- **识别语言文件**：文件名形如 `xx_xx.json`（`en_us.json`、`zh_cn.json`、`ja_jp.json`…），并与**同目录**的其它语言文件合并成一张大表。
- **原生注册为打开方式**：对语言文件双击仍走默认 JSON 编辑器，**绝不拦截**；用户可在“打开方式 / Reopen With…”里选择本编辑器，也可用右键菜单或命令面板打开。
- **多语言并排网格**：每行一个翻译 key，每列一种语言；直接在任意单元格编辑对应语言的译文；空单元格显示“未翻译”。
- **语言列开关**：顶部语言徽章点击可显示/隐藏列；徽章实时显示各语言翻译覆盖率（如 `en_us 42/50`）。
- **详情面板**：点击任意行，底部面板列出该 key 在所有语言下的多行文本框，便于对照翻译；**key 也可直接在详情中编辑**（重命名同步所有语言文件，`Enter` 提交 / `Esc` 还原）。详情面板支持**停靠到底部 / 左侧 / 右侧 / 全屏编辑**（拖动分隔条调整大小，停靠位置与尺寸会被记住）。
- **上下条目切换**：详情打开时用 `Ctrl+↑` / `Ctrl+↓`（或面板上的 ↑/↓ 按钮）在当前列表的上一条/下一条间跳转；`Ctrl+Shift+G` 可快速跳到指定的翻译 key（支持部分匹配）。
- **表格行右键菜单**：改为调用 **VS Code 原生右键菜单**（复制 key / 复制译文 / 复制整条 / 删除）；文本框内右键使用原生菜单后会自动恢复焦点与光标位置。
- **添加 / 删除 / 重命名 key**：对同目录**所有**语言文件同时生效，可撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`）。点“＋ 添加”直接在详情编辑面板以“草稿”方式新建：输入 key 后回车即创建，随后所有语言的译文在同一处继续编辑（无需单独的添加栏）。
- **代码补全**：key 输入框（添加/重命名）联想当前语言集已有 key（标注哪些语言缺失）与常见 Minecraft key 前缀；译文输入框联想其它语言中该 key 用到的 `%s` / `%d` / `%1$s` 占位符。
- **随 VS Code 主题与字体设置**：译文/key 的字号、字体跟随 VS Code `editor.fontSize` / `editor.fontFamily`（改动即时生效，行高自适应）；也可用 `minecraftLanguageEditor.fontSize` / `fontFamily` 独立覆盖（不设置时仍跟随代码编辑器）。整体配色使用当前主题的 CSS 变量（含编辑区、选区、补全弹窗等），key 与 `%s` 等占位符按“代码配色”高亮，切换主题自动跟随。界面文案跟随 VS Code 显示语言（中文/English），并保持简洁以免挤占编辑空间。
- **筛选 / 排序**：顶部搜索框即时过滤（匹配 key 或任意语言译文）；勾选“仅显示未翻译”；点击列头排序（key 列按字母序，语言列按其译文，再点切换升/降序）。
- **可拖拽列宽**：拖动列头右缘可调整该列宽度；在列头右缘双击可**自适应宽度**（按当前可见行中最长内容展开，网格过宽时横向滚动查看）。
- **占位符检查**：若某个 key 在不同语言间的 `%s` / `%d` / `%1$s` 占位符不一致，详情面板给出 ⚠ 提示。
- **外部修改同步**：文件在其它编辑器中被改动/保存时会自动从磁盘重载（GUI 中撤销历史随之清空）。
- **损坏 / 空文件友好**：空的或纯空白的语言文件会被当作“尚无译文的可编辑文件”正常打开并显示为语言列；JSON 解析失败或无法读取的文件会被隔离 —— 显示错误横幅、不会被改写，也**不会阻止**其它语言文件的打开与编辑。
- **格式保留**：写回时保留各文件原有的 key 顺序、缩进（空格/制表符）、末尾换行与 BOM；新 key 追加在文件末尾（diff 友好）。

## 如何打开 GUI（不会自动打开）

1. **资源管理器右键** `.json` 文件 → `Minecraft 语言文件: 用 GUI 编辑器打开`。
2. **Open With… / Reopen With…**（打开方式 / 重新打开方式）→ 选择 `Minecraft 语言文件编辑器 (GUI)`。
3. **命令面板**：`Minecraft 语言文件: 用 GUI 编辑器打开`（先打开或激活任意语言文件）。

若希望某类文件以后默认用它，可在 VS Code 设置 `workbench.editorAssociations` 中为该文件加一条，例如：

```json
"workbench.editorAssociations": {
  "**/lang/en_us.json": "minecraftLanguageEditor.gridEditor",
  "**/lang/zh_cn.json": "minecraftLanguageEditor.gridEditor"
}
```

> 语言文件命名必须是 Minecraft 风格的小写 `xx[_xx].json`；内容为**扁平字符串映射**（`{ "key": "译文" }`），这是标准语言文件格式。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（Mac: `Cmd`）——焦点在文本框内时只撤销/重做该框内的输入（无内容可撤销时静默无操作，不弹“没有可撤销的操作”提示）；焦点在表格/空白处时才撤销整表操作 |
| 聚焦搜索框 | `/` |
| 关闭详情 / 取消编辑 | `Esc` |
| 上一条 / 下一条（详情打开时） | `Ctrl+↑` / `Ctrl+↓` |
| 新建 key（对应“在下方插入行”） | `Ctrl+Enter` / `Ctrl+Shift+Enter` |
| 单元格内编辑（双击） | 回车提交；`Shift+回车` 换行；补全用 `↑↓ 回车/Tab/Esc` |
| 多选行 | 点击复选框，或 `Ctrl/⌘`+点击、`Shift`+点击连选 |
| 删除选中行 | 工具栏 🗑（或选中后按 `Delete`） |
| 重命名 key（详情面板） | 编辑 key 输入框，`Enter` 提交、`Esc` 还原 |

新建 key 的快捷键仅在焦点位于**表格或 key 编辑框**时生效；在译文编辑框中不会触发。

## 设置项（`minecraftLanguageEditor.*`）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `confirmDelete` | `true` | 删除翻译前弹出确认；确认框勾选“此后不再提醒”会自动关闭本项（可在此重新开启） |
| `detailDock` | `bottom` | 详情编辑面板默认停靠位置（`bottom`/`left`/`right`/`full`）；在 GUI 中切换停靠会自动写入本设置，因此关闭编辑器后仍会记住，也可直接在此修改 |
| `fontSize` | `null` | GUI 所有编辑文本的字号（px）；`null` 跟随 `editor.fontSize`，设置后独立于代码编辑器字号 |
| `fontFamily` | `null` | GUI 所有编辑文本的字体族；`null` 跟随 `editor.fontFamily` |
| `undoLimit` | `100` | 会话内撤销历史步数 |
| `indentSize` | `2` | 无法探测原缩进时写回使用的空格数（`0` = 单行压缩） |

## 工作原理简述

扩展将打开的文件所在目录视为“语言集合”：每个 `xx_xx.json` 是一列。扩展侧（extension host）维护合并模型与撤销栈，Webview 只是视图。每次修改通过 VS Code 的文本编辑 API 写透保存到磁盘，因此热退出、文档冲突提示等均由 VS Code 原生处理。撤销 / 重做对**受影响文件的整份内容**做快照回滚，保证跨文件操作可精确还原。

## 已知限制

- GUI 内的撤销历史仅存在于当前会话；窗口重开后标签由 VS Code 原生恢复并从磁盘重建（数据本身写透不会丢）。
- 若同一文件同时被其它工具编辑，以最后保存者为准（不做三方合并）；GUI 检测到外部修改时会自动重载并清空撤销历史。
- 不处理旧版 `.lang`（properties）格式——只面向 JSON 语言文件。
